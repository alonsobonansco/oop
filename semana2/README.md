Descripción:

Proyecto corresponde a un sistema de veterinaria para
no cometer errores al momento de registrar (trazabilidad)

```text
📁 src/
├── app/         # Contiene las clases de la lógica del negocio
└── main/        # Contiene la clase principal con el método main para iniciar la aplicación
```

Instrucciones para ejectuar:

Ir a la clase Main, ubicada en el paquete app. Hacer click derecho en cualquier 
parte del código (se abre un menú), seleccionar la opción que dice Run 
(tiene una imagen de flecha de color verde)
